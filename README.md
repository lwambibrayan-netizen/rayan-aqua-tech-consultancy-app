# Rayan Aqua Tech Consultancy

A polished, responsive single-page workspace for project tracking, hydraulic design, GIS layers, CAD sketches, costing, and technical reporting.

## Run locally

From the project root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- Responsive dashboard and sidebar navigation
- Project tracking with add/remove actions
- Hydraulic network editor with sample results
- GIS map panel with layer toggles
- CAD sketch canvas with length tracking
- Design calculators for demand, pipe sizing, pumps, and storage
- BOQ cost calculation and CSV export
- Draft technical report generation
- Team access and invitation panel
- Theme switcher and browser persistence
